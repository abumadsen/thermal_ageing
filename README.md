# thermal_ageing

Contains code to run all models and plots presented in the manuscript: "Ageing shifts reproductive thermal optimum to warmer temperatures in ostriches".  

1. TPC_5to8.R contains code for running thermal performance curve (TPC) analyses
2. heat_vs_cold_5to8 contains code for running models of reproductive heat and cold tolerance. Note that these models use posteriors from TPC analyses.
3. Figures contains code producing results figures in main manuscript (Fig 2-4), this includes estimating Thermal optimum and correlations.
